# Spenny

Build a clean, modern personal finance web app called MoneyMap that helps me see all of my money in one place, track bank accounts, income, expenses, savings, investments, and debts, and ultimately become debt-free. The app should include a dashboard showing net worth, cash flow, total debt, spending by category, and financial trends. Allow users to manually add accounts, transactions, and debts, create budgets, set savings goals, and track progress over time. Include a debt payoff planner using both the Snowball and Avalanche methods, showing estimated payoff dates and interest savings.
